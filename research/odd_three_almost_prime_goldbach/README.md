# 奇三殆素数的二元加法猜想

状态：**新提出的难猜想；没有严格的全称证明。** “新”指本存档中的新表述，有限文献检索不足以确认学术首创。

记 \(\Omega(m)\) 为计重数的素因子数。受[哥德巴赫猜想](../../pages/44758.wiki)、[刘维尔替换版 L01](../../liouville-prime-conjectures.md)以及三殆素数研究启发，提出：

> **猜想。** 每个偶整数 \(N\ge798\) 都有表示 \(N=a+b\)，其中 \(a,b\) 都是奇数，且 \(\Omega(a)=\Omega(b)=3\)。允许 \(a=b\)，也允许它们有公因子。

两个加数都是合数且刘维尔值为 \(-1\)，因此这比只要求 \(a,b\in\mathcal L\) 的 L01 强。下界 798 来自有限计算：796 不满足命题，故若猜想成立，798 是最小的连续偶数起点。

## 候选调整与有限检验

第一版额外要求 \(\gcd(a,b)=1\)。运行 `python3 check.py` 后，发现这个条件使许多偶数失败；在 \(N\le100000\) 范围有 610 个失败值，最后一个是 27720。因此不保留互素版。第二版只要求两个奇数均满足 \(\Omega=3\)。

程序用最小素因子筛求 \(\Omega\)，枚举每个偶数的两个奇数加数；又用独立试除核对了 \(m\le10000\) 的 \(\Omega(m)\)。默认范围内得到：

```text
Checked even N=6..1000000; trial division cross-check m<=10000
Exact-three failures: count=114, last=796
Coprime variant through 100000: count=610, last=27720
Largest first summand of first found pair: (539, 27304)
Example pairs: {798: (147, 651), 1000: (75, 925), 1000000: (45, 999955)}
```

例如 \(798=147+651=3\cdot7^2+3\cdot7\cdot31\)。这只证明**有限范围**内 \(798\le N\le10^6\) 的偶数均有表示，不能证明无限全称命题。

## 证明尝试与现有结果

先考虑能否从经典殆素数加法定理直接推出。Togashi–Uchiyama 的[1964 年论文](https://eprints.lib.hokudai.ac.jp/dspace/bitstream/2115/56055/1/JFSHIU_18_N1-2_060-068.pdf)证明：充分大的偶数是两个各有**至多** 3 个素因子的整数之和。其证明还找到与 \(N\) 互素的加数，但不能强制两加数的 \(\Omega\) **恰好**为 3，也不给出 798 这样的小而明确的起点。因此目前没有从该定理到本猜想的严格推论。[Chen 定理](https://dlmf.nist.gov/27.13)给出充分大偶数的“素数 + 至多两个素因子的数”表示，同样不能推出两个加数均恰有 3 个素因子。

另一种尝试是取 \(a=pq^2\)、\(b=rs^2\)（\(p,q,r,s\) 为奇素数），这会自动给出 \(\Omega(a)=\Omega(b)=3\)。但要求每个大偶数都能写成这种受限形式，本身是尚未解决的统一加法问题；它也未覆盖所有 \(\Omega=3\) 加数。因此目前的主要缺口是对每个偶数 \(N\) 证明其奇 \(\Omega=3\) 加法表示数为正，随后还需处理有限起点与大数论证之间的范围。

未取得严格证明，所以暂不按“已证明成果”给难度、创新性、方法论或工具打分。此条作为新的难猜想记录，供后续研究。
