# 平方窗口中的刘维尔负值奇合数

状态：**研究猜想，尚无严格证明；新颖性未获全面文献确认。** 2026-09-23 从[数论猜想索引](../../number_theory_index.csv)中的勒让德、奥佩曼平方区间问题与[刘维尔替换集](../../liouville-prime-conjectures.md)出发提出。这里要求证据必须是**合数**，所以素数版勒让德猜想即使成立也不会直接给出所需见证。

记 \(\Omega(m)\) 为按重数计算的素因子数，\(\lambda(m)=(-1)^{\Omega(m)}\)。令

\[
C(n)=\#\{m:n^2<m<(n+1)^2,\ m\text{ 是奇合数且 }\lambda(m)=-1\}.
\]

## 两次候选与计算结果

1. 失败的候选：\(C(n)\ge1\) 对每个 \(n\ge5\)。反例 \(n=17\)：区间 \((289,324)\) 内没有所需整数。故不把它留作猜想。
2. **保留的候选（双平方窗口猜想）**：对每个整数 \(n\ge5\)，

   \[
   C(n)+C(n+1)\ge1.
   \]

   等价地，开区间 \((n^2,(n+2)^2)\) 内存在一个奇合数 \(m\)，使 \(\Omega(m)\) 为奇数（必至少为 3）。

运行 `python3 check.py --bound 3000`，逐一分解到 \((3002)^2\) 的整数，并对 \(5\le n\le3000\) 检查：第一候选只有 \(n=17\) 失败；第二候选无反例，且每个双窗口至少找到 2 个见证。程序还用独立试除复核 10000 以下奇数的刘维尔符号与合数判定。这个结果只证明上述**有限范围**，不能推出全称猜想。

## 已证明的较弱界

**命题。** 每个整数 \(n\ge2\) 的区间 \((n^2,(n+4)^2)\) 都含有奇合数 \(m\)，满足 \(\lambda(m)=-1\)。

**证明。** 取使 \(3q^2>n^2\) 的最小奇正整数 \(q\)。因 \(n\ge2\)，有 \(q\ge3\)。最小性给出 \(3(q-2)^2\le n^2\)，所以 \(\sqrt3q\le n+2\sqrt3<n+4\)。于是 \(n^2<3q^2<(n+4)^2\)。令 \(m=3q^2\)：它是奇合数，而且 \(\Omega(m)=1+2\Omega(q)\) 为奇数。证毕。

这个构造的宽度是 4 个平方间隔；候选要求宽度 2。单靠同一个 \(3q^2\) 构造，无法把最坏间距从约 \(2\sqrt3\,n\) 降到 \(2n\) 的尺度。下一步应寻找能与 \(3q^2\) 的空隙互补的第二类可控构造，或建立直接控制奇合数刘维尔符号的短区间估计。

进一步检查了 \(m=pq^2\) 的显式族，其中 \(p\in\{3,5,7,11,13,17,19\}\) 且 \(q\ge3\) 为奇数。该族在 \(5\le n\le3000\) 的 125 个双窗口中**没有**给出见证；第一个是 \(n=26\)。这些窗口内仍有其他类型的见证，说明只叠加几个固定平方倍数还不足以证明候选。

## 与已有结果的关系

- [Campbell 2026](https://arxiv.org/abs/2603.10356)证明每个相邻平方区间存在 \(\Omega\le3\) 的整数，但该整数可能是素数、半素数或偶数，不能保证它是本猜想要求的奇合数且 \(\Omega\) 为奇数。
- [Teräväinen 2024](https://arxiv.org/abs/2010.07924)研究多项式自变量上的刘维尔符号变化；其结论不是对**每一个**这样的短平方窗口给出奇合数见证。
